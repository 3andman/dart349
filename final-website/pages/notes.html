Artist Statement

My project is a simulated Windows XP interface that uses nostalgia to create a familiar and “safe” digital space. It recreates a login screen, desktop, and application pages based on early 2000s operating systems.

This nostalgic environment is used to explore blame culture and how it operates in modern life, where people are often judged for errors rather than supported and taught how to resolve them. The system responds to user actions with criticism and resistance, especially through the character “Clippy”, an assistant from windows xp that was implemented to help users navigate their new system, but in my program he reinforces mistakes instead of helping correct them.

Overall, the work uses a nostalgic interface to make this experience more accessible and relatable, while revealing how digital systems and social environments can quietly normalize blame over guidance.
